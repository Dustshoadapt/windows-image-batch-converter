## 🛠️ Troubleshooting

- Ensure the downloaded archive is named exactly **`WindowsImageBatchConverter.zip`**.

- The output is blurry: increase the chosen quality or size settings.
- Conversion stops: check disk space and access to the destination folder.
- **Download returns 404:** The release has not yet been published or its asset is not named `WindowsImageBatchConverter.zip`.
